ИНСТРУКЦИЯ ПО РЕДАКТИРОВАНИЮ ФОТО-ПОРТФОЛИО

Привет!
Этот файл поможет тебе изменить контент и некоторые базовые стили на сайте. Все изменения делаются в одном файле.

---
ЧТО ТЕБЕ НУЖНО СДЕЛАТЬ:

1.  ОТКРОЙ ФАЙЛ "index.html" в БЛОКНОТЕ (или любом другом текстовом редакторе, например, Notepad++).
    (Не открывай его в браузере для редактирования!)

2.  НАЙДИ БЛОК НАСТРОЕК:
    Прокрути файл вниз, пока не увидишь большую секцию, которая начинается с:

    // =========================================================================
    //  БАЗОВЫЕ НАСТРОЙКИ И КОНТЕНТ. РЕДАКТИРОВАТЬ ТОЛЬКО ЭТОТ БЛОК!
    // =========================================================================

    И заканчивается на:

    // =========================================================================
    //  КОНЕЦ БЛОКА НАСТРОЕК. ДАЛЕЕ КОД НЕ РЕДАКТИРОВАТЬ!
    // =========================================================================

    Всё, что между этими строками - это твой контент и настройки.

3.  ИЗМЕНИ КОНТЕНТ И НАСТРОЙКИ:

    * `"site"`: Общие настройки сайта.
        * `"title"`: "Илья Пилипенко" - измени на свое имя (отображается в заголовке сайта и мобильном меню).
        * `"email"`: "ilpilipenko@gmail.com" - свой адрес электронной почты.
        * `"socialLinks"`: здесь ты можешь добавить или удалить ссылки на Instagram, Telegram и т.д.
            * `"platform"`: название соцсети (для себя).
            * `"url"`: ссылка на твой профиль.
            * `"iconClass"`: класс иконки Font Awesome (например, `fab fa-instagram`, `fab fa-telegram-plane`). Если нужна другая иконка, можно найти ее на сайте Font Awesome (fontawesome.com).
    
    * `"seo"`: Настройки для поисковой оптимизации (мета-теги).
        * `"description"`: Короткое описание сайта, которое будет отображаться в результатах поиска.
        * `"keywords"`: Ключевые слова, по которым пользователи могут найти твой сайт. Разделяй слова запятыми.
        * `"author"`: Имя автора сайта.

    * `"about"`: Контент для всплывающего окна "Обо мне".
        * `"title"`: заголовок окна.
        * `"role"`: твоя роль/профессия.
        * `"paragraphs"`: абзацы текста. МОЖНО ИСПОЛЬЗОВАТЬ HTML-ТЕГИ! Например, `<a href="...">ссылка</a>` или `<b>жирный текст</b>`. Но будь осторожен с ними.

    * `"navigation"`: Список пунктов меню в левой боковой панели.
        * `"id"`: уникальное название для этой секции (не меняй, если не знаешь зачем).
        * `"label"`: Текст, который будет виден в меню.
        * `"type"`: не меняй (`"gallery"`, `"text"` (для Bio), `"overlay"` (для About)).

    * `"galleriesData"`: Это список твоих фотогалерей.
        * Каждый блок `{...}` - это одна галерея. Ты можешь скопировать готовый блок и изменить его, чтобы добавить новую галерею.
        * `"id"`: уникальный идентификатор галереи (должен быть в списке `"navigation"` выше).
        * `"title"`: название галереи.
        * `"folder"`: **ОЧЕНЬ ВАЖНО!** Это **имя папки** внутри главной папки `photos/`, где лежат фотографии именно для ЭТОЙ галереи.
            * Пример: Если у тебя есть папки `MyPhotoPortfolio/photos/мои_портреты/` и `MyPhotoPortfolio/photos/пейзажи/`, то для галереи с портретами ты пишешь `"folder": "мои_портреты"`, а для пейзажей - `"folder": "пейзажи"`.
            * Убедись, что имя папки здесь **ТОЧНО** совпадает с именем реальной папки на диске (включая регистр букв!).
        * `"description"`: описание галереи. Если не нужно, поставь `null` (без кавычек).
            * `"text"`: короткое описание.
            * `"moreText"`: дополнительный текст, который скрыт. Если не нужен, удали эту строку или оставь пустой.
            * `"showToggle"`: `true`, если нужна кнопка "i" для показа/скрытия "moreText"; `false`, если не нужна. Если `description: null`, то кнопки не будет.
        * `"imageCount"`: !!! САМОЕ ВАЖНОЕ !!! ЭТО КОЛИЧЕСТВО ФОТОГРАФИЙ В ЭТОЙ КОНКРЕТНОЙ ГАЛЕРЕЕ.
            * Все твои фотографии должны лежать в соответствующей папке (например, `photos/мои_портреты/`).
            * Они должны быть названы `01.jpg`, `02.jpg`, `03.jpg` и так далее, по порядку (две цифры).
            * Если у тебя 15 фотографий, последняя должна быть `15.jpg`, а `imageCount` должен быть `15`.
        * `"layoutClass"`: меняет внешний вид галереи (выбери один из вариантов):
            * `"gallery-single-column"` (фото в один столбец)
            * `"gallery-two-columns"` (фото в два столбца)
            * `"gallery-three-columns"` (фото в три столбца)
            * `"gallery-horizontal-scroll"` (горизонтальная прокрутка)

    * `"bio"`: Контент для секции "Bio". Аналогично `"about"`, можно использовать HTML-теги.

    * `"styles"`: Стили сайта (акцентный цвет и шрифт).
        * `"accentColor"`: Измени цвет акцентов на сайте (например, кнопок, активных ссылок). Используй HEX-код цвета (например, `#FF5733` для оранжевого, `#007bff` для синего).
        * `"fontFamily"`: Название шрифта (например, `'Arial', sans-serif` или `'Georgia', serif`). Если указываешь несколько, то они будут использоваться как запасные, если первый не найдется у пользователя. Лучше использовать стандартные системные шрифты.

4.  СОХРАНИ ФАЙЛ "index.html".

5.  ЗАГРУЗИ ФОТОГРАФИИ В ПРАВИЛЬНЫЕ ПАПКИ:

    * Убедись, что у тебя есть главная папка `MyPhotoPortfolio/`.
    * Внутри нее должна быть папка `photos/`.
    * **Внутри папки `photos/` создай отдельные подпапки для каждой твоей галереи.** Имена этих подпапок должны ТОЧНО совпадать с тем, что ты указал в поле `"folder"` для каждой галереи в `index.html`.
        * Пример:
            ```
            MyPhotoPortfolio/
            ├── index.html
            ├── README.txt
            └── photos/
                ├── gallery1_images/   <-- здесь лежат 01.jpg, 02.jpg, ... для "Галерея 1"
                │   ├── 01.jpg
                │   ├── 02.jpg
                │   └── ...
                ├── gallery2_images/   <-- здесь лежат 01.jpg, 02.jpg, ... для "Галерея 2"
                │   ├── 01.jpg
                │   └── ...
                └── my_project_name/   <-- здесь лежат фото для "Мой Проект"
                    ├── 01.jpg
                    └── ...
            ```
    * В каждой из этих подпапок фотографии должны быть названы **строго** `01.jpg`, `02.jpg`, `03.jpg` и так далее (две цифры). Регистр расширения (`.jpg` или `.JPG`) не так важен, скрипт попробует оба варианта.

6.  КАК ПОСМОТРЕТЬ РЕЗУЛЬТАТ:
    Просто открой файл "index.html" в своем веб-браузере (дважды кликни по нему). Все должно работать без установки чего-либо еще!

---
ВАЖНОЕ ПРИМЕЧАНИЕ:
* Будь осторожен с кавычками `""` и запятыми `,` в блоке настроек JavaScript. Одна лишняя или отсутствующая запятая может сломать сайт.
* Если что-то сломалось, проверь консоль разработчика в браузере (нажми F12, перейди на вкладку "Console") – там обычно видно, где ошибка.
